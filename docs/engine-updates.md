위 리비전은 업데이트 시작 시점에 확인한 공식 main입니다. FigCraft는 공식 Git 이력을
병합하며, FilmCraft 엔진·프로젝트·코덱·렌더러는 같은 리비전의 Git 의존성을 사용합니다.
FilmCraft 프런트엔드는 공식 이전 버전 / Purpose 수정본 / 공식 최신 버전의 3방향 병합입니다.
서식 차이를 먼저 정규화하여 로컬 수정을 일반 코드 교체로 덮어쓰지 않습니다.

## 유지하는 기능과 연동

- Paper Liquid Metal, 7종 이미지 필터와 Water 애니메이션, Papierwerk 바깥 종이 테두리,
  BiRefNet 배경 제거와 원본 복원, Custom 패널 및 슬라이더/직접 입력.
- 기존 파일의 커스텀 효과 종류·매개변수·효과 순서·실행 취소. 최신 누적 블러/그림자
  영역 계산에 종이 테두리의 로컬 좌표 확대를 결합합니다. 렌더러가 실제로 할당하는
  레이어와 문서의 영역 계산 모두에 같은 종이 여백을 적용해 바깥 테두리가 잘리지 않게 합니다.
- Purpose의 브라우저 탭·창 버튼·사이드바·글꼴/배율 설정·로고·Lucide 아이콘과 FigCraft Home 제외.
- 라이브러리 표시 이름과 전용 bin, 상대 경로 해석, 비동기 가져오기, 참조 보존,
  삭제/실행 취소 동기화, 영상별 프로젝트·대본·가이드·기록·백업·Codex 연동.
- FilmCraft 버튼·F11/Esc가 같은 호스트 창을 제어하는 전체화면 경로, 정확한 클라이언트 크기,
  이전 창 크기 복원, 디자인 전체화면과 구분선.
- 개인 Fork의 설치 파일 배포와 업데이트 안내. 공식 FigCraft/FilmCraft 바이너리 자동 교체를
  활성화하지 않습니다.

## API 적응

FilmCraft의 실행 취소 기록에 추가된 명령 ID를 사용해 표시 라벨이 바뀌어도 소스 동기화를
유지합니다. 직접 편집으로 생성된 옛 기록은 기존 라벨 해석을 계속 사용합니다.
GPU 내보내기 어댑터는 최신 `FrameRenderer::caps`를 전달합니다. 데스크톱 오디오 입출력도
동일 리비전으로 갱신하고 별도 스레드의 스크러빙 오디오 출력을 연결합니다.
최신 UI에 추가된 아이콘은 기존 허가된 Lucide 원본에 연결하고 글자 크기 배율을 적용합니다.
FigCraft의 새 렌더 워커 경로에도 커스텀 효과의 애니메이션 시간을 전달합니다.
Paper 원본 GLSL 파일과 수식은 유지합니다. GPU 어댑터는 CMYK의 `inout` 채널을
동등한 스칼라 누적 변수로 전달하여 Naga의 벡터 요소 포인터 오류를 피합니다.
Liquid Metal의 너비 0 이미지 프레임은 명시적인 hard clip으로 전달합니다. GLSL이
정의하지 않은 같은 경계의 `smoothstep` 때문에 Vulkan에서 이미지가 투명해지던
문제를 해소하며, 원본 알파 모양과 애니메이션을 유지합니다.

## 이후 갱신 절차

1. 작업 트리와 현재 배포 커밋을 확인하고 공식 main을 가져와 고정 리비전을 기록합니다.
2. 별도 브랜치에서 FigCraft를 3방향 병합하고 커스텀 데이터·렌더러·UI 접점을 검토합니다.
3. FilmCraft Git 의존성과 프런트엔드를 같은 리비전으로 갱신합니다. `UPSTREAM.md`의
   호스트 적응 목록과 오디오·GPU 어댑터를 함께 확인합니다.
4. 잠금 파일, 포맷/Clippy, 엔진·커스텀 효과·앱 테스트와 WASM을 검사합니다. 이전 배포본이
   저장한 합성 프로젝트를 새 앱에서 열고, 네이티브 화면에서 디자인과 편집을 확인합니다.
5. Windows 설치 후 검사에서 기존 전체화면 버튼·F11/Esc·복원·정확한 창 크기·아이콘·
   Codex 프로토콜·미디어 도구를 검사한 뒤 새 버전의 installer EXE만 배포합니다.

이번 업데이트의 실제 실행 결과와 제한은 [VALIDATION.md](../VALIDATION.md)에 기록합니다.
