# Papierwerk 찢어진 종이 테두리

이 빌드는 **v0.11.2.5 (`273bdf51`)**의 파일 상태를 바탕으로 Papierwerk를 추가했습니다.
v0.11.2.6의 안쪽 침식 효과와 전체 매개변수 번역은 포함하지 않습니다.
기존 Liquid Metal, 7개 Image Filters, 슬라이더와 BiRefNet은 .5 그대로 유지합니다.
배포 이력은 보존하며 새 Preview 번호로 구분합니다.

ZIP의 **Open Papierwerk.cmd**를 실행하면 어두운 바탕 위의 편집 가능한 예제를 바로 볼 수 있습니다.

사진·투명 PNG·도형을 선택하고 **디자인 → 커스텀 → + → 찢어진 종이 (Papierwerk)**를 고릅니다.
효과 설정에서 **바깥 테두리 폭**, **찢김 불규칙도**, **무늬 번호**, **종이 테두리 색상**을 조절합니다.
불투명한 원본 픽셀을 그대로 두고 그 뒤에 종이를 덧대므로, 오브젝트 바깥으로 테두리가 생깁니다.
폭을 0으로 하거나 눈 아이콘을 끄거나 효과를 삭제하면 원래 외형으로 돌아갑니다.
색상의 불투명도도 조절할 수 있습니다. 숫자 입력과 슬라이더, 한 번의 드래그에 한 번의 실행 취소를 지원합니다.

레이어 자체 치수는 유지하고, 렌더링·내보내기 영역은 종이가 추가된 만큼 넓어집니다.
그림자는 추가된 종이 윤곽을 따라갑니다. 상위 프레임의 내용 자르기를 켜면 프레임 밖 부분은 잘립니다.
투명 이미지에서는 알파 윤곽을 따라 종이가 생기므로 BiRefNet으로 배경을 제거한 이미지에도 쓸 수 있습니다.
반투명한 원본 가장자리에는 뒤의 종이색이 비칩니다.

`.figcraft`에는 편집 가능한 효과를 저장합니다. PNG/JPEG/WebP는 캔버스와 같은 계산을 사용하고,
SVG/PDF는 효과가 있는 레이어를 래스터로 포함합니다. `.fig`와 Android Vector Drawable은 이 효과를
지원하지 않아 생략 경고를 표시합니다. 로컬 CPU 효과이며 모델이나 서버 통신이 필요 없습니다.

Papierwerk의 `addTornBorder`, 정확한 거리 변환과 노이즈를 Rust로 이식했습니다.
