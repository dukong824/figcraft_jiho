# Purpose video maker

`purpose-video-maker`는 FigCraft 편집기를 영상 프로젝트 안에 넣은 로컬 데스크톱 앱입니다.
기존 `figcraft` 실행 파일과 문서 형식은 그대로 사용할 수 있습니다.

## 실행

```sh
cargo run --locked -p figcraft --bin purpose-video-maker
# 기존 실행 파일에서도 가능
cargo run --locked -p figcraft --bin figcraft -- --video-maker
```

프로젝트는 운영체제의 FigCraft 설정 폴더 아래 `Purpose video maker`에 저장됩니다.
다른 폴더를 쓰려면 `PURPOSE_PROJECTS_DIR` 환경 변수를 지정하세요. 각 영상의 `design.figcraft`,
가져온 에셋, 내보낸 영상은 그 폴더 안에 있습니다. 영상과 채널 이름, 대본, 타임라인은
`workspace.json`에 자동 저장됩니다. 에셋은 원본 경로에 대한 링크가 아닌 프로젝트 내 복사본입니다.

## 상단 탭과 창

상단의 `+`는 빈 작업 탭을 엽니다. 왼쪽에서 영상의 라이브러리·대본·디자인·편집을
선택하면 현재 탭에서 열리고, `Ctrl+클릭`하면 새 탭에서 엽니다. 각 탭은 별도의
뒤로·앞으로 기록을 유지합니다. `Ctrl+T`로 새 탭을 열고 `Ctrl+W`로 현재 탭을
닫을 수 있으며, `Alt+←` / `Alt+→`로 기록을 이동합니다. 왼쪽 위 버튼은 사이드바를
접거나 펼칩니다. Windows와 Linux에서는 상단 탭이나 빈 부분을 드래그해 창을
움직이고, 오른쪽에서 최소화·최대화/복원·닫기를 사용할 수 있습니다.

## 제작 흐름

1. 채널의 `+`로 영상을 만듭니다. 대본 제목과 영상 이름은 같습니다. 대본 제목을 바꾸면
   사이드바·탭·상단 경로도 바뀝니다. 영상에 마우스를 올리면 아이콘 자리에 펼침 버튼이
   나타납니다. 각 영상의 펼침 상태는 따로 저장되며, 다른 영상을 열어도 유지됩니다.
2. **라이브러리**에 영상·오디오·이미지 또는 `.figcraft` 파일을 가져오거나 드롭합니다.
   목록에서는 파일 이름을 간결하게 보고, 타일에서는 이미지와 영상의 썸네일을 봅니다.
   보기 버튼으로 전환하거나 이름으로 검색할 수 있습니다. 파일을 대본에 첨부하거나
   편집 타임라인에 추가할 수 있습니다.
3. **대본**에서 제목 아래의 자유형 문서에 글을 작성합니다. 변경 사항은 자동으로
   저장되며, 이전 블록형 대본은 제목·본문·첨부 파일로 자동 변환됩니다.
4. **디자인**에서는 홈 화면을 제외한 FigCraft 편집기를 사용합니다. 각 영상에는
   별도의 `design.figcraft`가 생깁니다. 화면 상단의 **디자인을 라이브러리에 저장**은
   현재 선택 요소 또는 페이지를 PNG로 내보내 라이브러리에 추가합니다.
5. **편집**에서 영상 클립의 순서와 앞뒤 트림, 오디오 클립의 시작 시각과 볼륨,
   자막의 시작·끝과 내용을 조정한 뒤 MP4로 내보냅니다. 내보낸 파일과 SRT는
   해당 영상의 `exports` 폴더에 저장됩니다.

소스 실행 시 FFmpeg의 `ffmpeg`, `ffprobe`, `ffplay` 명령이 PATH에 있어야 합니다.
Windows 배포본에는 세 도구가 포함되며, 실행 파일 옆 `ffmpeg/bin`에서 자동으로 찾습니다. `ffplay`는
소스 재생에만 필요합니다. 타임라인은 현재 영상 클립을 순서대로 잇고 오디오를
섞습니다. 앱 내부 미리보기는 선택한 클립의 정지 프레임이며, 소리와 움직임은
**소스 재생**을 누르면 별도 `ffplay` 창에서 확인할 수 있습니다. 자막은 MP4의
선택 가능한 자막 트랙과 SRT로 저장되며 화면에 굽지 않습니다.

## Codex 보조

왼쪽 아래 **Codex**를 클릭하면 현재 탭의 오른쪽에 패널이 열립니다. 같은 버튼이나
패널의 `×`로 닫습니다. 라이브러리와 디자인 탭에서도 사용할 수 있습니다.
Windows 배포본에는 공식 Codex CLI 0.165.0과 라이선스가 포함됩니다.
**ChatGPT 계정 연결**을 누르고 브라우저에서 로그인합니다. 브라우저 연결이 어려우면
**계정 및 CLI 연결 → 기기 코드로 로그인**을 사용합니다. 연결 상태 확인, 로그아웃,
별도 CLI 실행 파일 선택도 같은 메뉴에 있습니다. 인증은 공식 CLI가 처리하며 앱은
인증 정보를 읽거나 별도로 저장하지 않습니다.

현재 영상의 대본·에셋·타임라인을 읽기 전용으로 전달하고, 답변을 검토한 뒤 대본에
추가합니다. ChatGPT 로그인만 허용하며 API 키 환경 변수는 채팅 프로세스에 전달하지
않습니다. Codex 사용 가능 여부와 한도는 연결한 계정의 구독 상태를 따릅니다.
소스 실행에서는 PATH의 `codex` 또는 직접 선택한 CLI를 사용합니다.

## 수정 기록과 휴지통

왼쪽 아래 **수정 기록**은 현재 영상의 대본·에셋 목록·편집 설정 기록을 보여 줍니다.
입력이 잠시 멈추거나 영상을 전환·종료할 때 기록하며, 전체 프로젝트의 최근 100개를
보관합니다. 이전 대본을 미리 보고 **이 버전으로 복원**할 수 있습니다. FigCraft 디자인
파일의 내부 편집 이력은 이 기록에 포함되지 않습니다.

영상의 오른쪽 클릭 메뉴에서 **휴지통으로 이동**하면 목록에서 숨겨집니다.
왼쪽 아래 **휴지통 → 복원**으로 원래 채널에 되돌릴 수 있습니다. 에셋과 디자인 파일은
삭제하지 않습니다.

## 현재 범위

이 버전은 로컬 영상 제작의 첫 번째 완결된 흐름입니다. 클립을 끌어놓는 다중
비디오 트랙, 전환 효과, 키프레임, 앱 안의 연속 재생·오디오 모니터링, 하드웨어
인코딩은 아직 없습니다. 영상은 1280×720, 30fps H.264/AAC MP4로 내보냅니다.
Windows x64 설치 파일과 포터블 ZIP은 `packaging/purpose-video-maker/package.ps1`로
빌드합니다. 설치는 사용자 계정 아래에만 적용되며, 프로젝트 데이터는 설치 폴더 밖에
저장됩니다. CI의 `Purpose video maker Windows package` 작업은 설치 후 실행 및
포함된 FFmpeg의 H.264 인코딩까지 확인합니다. 설치 파일은 코드 서명되지 않았습니다.
