# Purpose video maker

`purpose-video-maker`는 FigCraft 편집기를 영상 프로젝트 안에 넣은 로컬 데스크톱 앱입니다.
기존 `figcraft` 실행 파일과 문서 형식은 그대로 사용할 수 있습니다.

## 실행

```sh
cargo run --locked -p figcraft --bin purpose-video-maker
# 기존 실행 파일에서도 가능
cargo run --locked -p figcraft --bin figcraft -- --video-maker
```

프로젝트는 운영체제의 FigCraft 설정 폴더 아래 `Purpose video maker`에 저장됩니다.
다른 폴더를 쓰려면 `PURPOSE_PROJECTS_DIR` 환경 변수를 지정하세요. 각 영상의 `design.figcraft`,
가져온 에셋, 내보낸 영상은 그 폴더 안에 있습니다. 영상과 채널 이름, 대본, 타임라인은
`workspace.json`에 자동 저장됩니다. 에셋은 원본 경로에 대한 링크가 아닌 프로젝트 내 복사본입니다.

## 제작 흐름

1. 왼쪽에서 채널과 영상을 만들고 영상 이름을 편집합니다.
2. **라이브러리**에 영상·오디오·이미지 또는 `.figcraft` 파일을 가져오거나 드롭합니다.
   라이브러리의 파일을 대본에 첨부하거나 편집 타임라인에 추가할 수 있습니다.
3. **대본**에 제목, 문단, 장면 블록을 작성하고 라이브러리 에셋을 참조합니다.
4. **디자인**에서는 홈 화면을 제외한 FigCraft 편집기를 사용합니다. 각 영상에는
   별도의 `design.figcraft`가 생깁니다. 화면 상단의 **디자인을 라이브러리에 저장**은
   현재 선택 요소 또는 페이지를 PNG로 내보내 라이브러리에 추가합니다.
5. **편집**에서 영상 클립의 순서와 앞뒤 트림, 오디오 클립의 시작 시각과 볼륨,
   자막의 시작·끝과 내용을 조정한 뒤 MP4로 내보냅니다. 내보낸 파일과 SRT는
   해당 영상의 `exports` 폴더에 저장됩니다.

소스 실행 시 FFmpeg의 `ffmpeg`, `ffprobe`, `ffplay` 명령이 PATH에 있어야 합니다.
Windows 배포본에는 세 도구가 포함되며, 실행 파일 옆 `ffmpeg/bin`에서 자동으로 찾습니다. `ffplay`는
소스 재생에만 필요합니다. 타임라인은 현재 영상 클립을 순서대로 잇고 오디오를
섞습니다. 앱 내부 미리보기는 선택한 클립의 정지 프레임이며, 소리와 움직임은
**소스 재생**을 누르면 별도 `ffplay` 창에서 확인할 수 있습니다. 자막은 MP4의
선택 가능한 자막 트랙과 SRT로 저장되며 화면에 굽지 않습니다.

## Codex 보조

대본과 편집 탭의 오른쪽 패널은 현재 영상의 대본, 에셋 이름과 길이, 타임라인을
Codex CLI에 전달해 조언이나 수정안을 받습니다. 요청을 보내면 Codex가 프로젝트
폴더를 읽기 전용으로 사용하고 파일은 직접 변경하지 않습니다. 대본 탭에서는
응답을 검토한 뒤 새 문단으로 추가할 수 있습니다. 사용하려면 `codex` CLI를 설치하고
본인의 ChatGPT 계정으로 로그인해야 합니다. 앱은 별도 API 키를 요구하지 않지만
Codex 사용 가능 여부와 한도는 사용자의 구독·계정 상태를 따릅니다.

## 현재 범위

이 버전은 로컬 영상 제작의 첫 번째 완결된 흐름입니다. 클립을 끌어놓는 다중
비디오 트랙, 전환 효과, 키프레임, 앱 안의 연속 재생·오디오 모니터링, 하드웨어
인코딩은 아직 없습니다. 영상은 1280×720, 30fps H.264/AAC MP4로 내보냅니다.
Windows x64 설치 파일과 포터블 ZIP은 `packaging/purpose-video-maker/package.ps1`로
빌드합니다. 설치는 사용자 계정 아래에만 적용되며, 프로젝트 데이터는 설치 폴더 밖에
저장됩니다. CI의 `Purpose video maker Windows package` 작업은 설치 후 실행 및
포함된 FFmpeg의 H.264 인코딩까지 확인합니다. 설치 파일은 코드 서명되지 않았습니다.
