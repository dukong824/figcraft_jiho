# Purpose video maker

`purpose-video-maker`는 FigCraft 편집기를 영상 프로젝트 안에 넣은 로컬 데스크톱 앱입니다.
기존 `figcraft` 실행 파일과 문서 형식은 그대로 사용할 수 있습니다.

## 실행

```sh
cargo run --locked -p figcraft --bin purpose-video-maker
# 기존 실행 파일에서도 가능
cargo run --locked -p figcraft --bin figcraft -- --video-maker
```

Linux에서 소스로 빌드할 때는 기존 GUI 의존성에 더해 ALSA 개발 파일과 pkg-config가
필요합니다. Debian/Ubuntu에서는 `libasound2-dev`, `pkg-config` 패키지를 설치하세요.

프로젝트는 운영체제의 FigCraft 설정 폴더 아래 `Purpose video maker`에 저장됩니다.
다른 폴더를 쓰려면 `PURPOSE_PROJECTS_DIR` 환경 변수를 지정하세요. 각 영상의 `design.figcraft`,
가져온 에셋, 편집 프로젝트는 그 폴더 안에 있습니다. 영상과 채널 이름, 대본은
`workspace.json`, FilmCraft 타임라인은 영상별 `edit.fcproj`에 자동 저장됩니다. 에셋은 원본 경로에 대한 링크가 아닌 프로젝트 내 복사본입니다.

## 상단 탭과 창

상단의 `+`는 빈 작업 탭을 엽니다. 왼쪽에서 영상의 라이브러리·대본·디자인·편집을
선택하면 현재 탭에서 열리고, `Ctrl+클릭`하면 새 탭에서 엽니다. 각 탭은 별도의
뒤로·앞으로 기록을 유지합니다. `Ctrl+T`로 새 탭을 열고 `Ctrl+W`로 현재 탭을
닫을 수 있으며, `Alt+←` / `Alt+→`로 기록을 이동합니다. 왼쪽 위 버튼은 사이드바를
접거나 펼칩니다. Windows와 Linux에서는 상단 탭이나 빈 부분을 드래그해 창을
움직이고, 오른쪽에서 최소화·최대화/복원·닫기를 사용할 수 있습니다.
`Ctrl+휠`로 전체 UI 크기를 조절하고 `Ctrl+0`으로 기본 크기로 되돌립니다. 크기는 저장됩니다.
FilmCraft의 전체화면 버튼과 `F11`로 전체화면을 전환하고 `Esc`로 나갑니다.
편집 전체화면에서는 상단 탭·사이드바·Codex 패널을 숨겨 편집기가 모니터 전체를 사용하며,
나오면 창 크기·위치·최대화 여부와 원래 레이아웃을 복원합니다.

## 제작 흐름

1. 채널의 `+`로 영상을 만듭니다. 대본 제목과 영상 이름은 같습니다. 대본 제목을 바꾸면
   사이드바·탭·상단 경로도 바뀝니다. 영상에 마우스를 올리면 아이콘 자리에 펼침 버튼이
   나타납니다. 채널도 아이콘에 마우스를 올려 접거나 펼칩니다. 채널과 영상의 펼침 상태는 각각 저장됩니다. 영상 행의 `⋯` 메뉴에서 이름을 바꾸거나 휴지통으로 이동합니다.
2. **라이브러리**에 영상·오디오·이미지 또는 `.figcraft` 파일을 가져오거나 드롭합니다.
   목록에서는 파일 이름을 간결하게 보고, 타일에서는 이미지와 영상의 썸네일을 봅니다.
   이름이 길면 목록은 한 줄, 타일은 두 줄에서 말줄임하고 드래그할 때 썸네일이 따라옵니다.
   보기 버튼으로 전환하거나 이름으로 검색할 수 있습니다. 파일을 사이드바의 대본·디자인·편집
   항목으로 끌어 놓아 바로 사용합니다. 다른 영상으로 드롭하면 원본을 유지한 복사본을
   대상 라이브러리에 추가하며 같은 원본을 다시 드롭해도 라이브러리에 중복 생성하지 않습니다.
   이미지·디자인은 디자인 탭에, 영상·오디오·이미지는 편집 탭에 드롭할 수 있습니다.
3. **대본**에서 제목 아래의 자유형 문서에 글을 작성합니다. 변경 사항은 자동으로
   저장되며, 이전 블록형 대본은 제목·본문·첨부 파일로 자동 변환됩니다. 텍스트를 더블클릭·트리플클릭하거나 드래그해 선택하면 서식 메뉴가 나타납니다.
   굵게·기울임·밑줄·취소선, 일반 텍스트·제목 1–4·글머리 기호, 선택한 글자의 크기와
   행간을 조절합니다. Ctrl+B/I/U 단축키와 Ctrl+Z / Ctrl+Shift+Z도 지원합니다.
   이미지는 실제 본문에 표시되며 원하는 줄 아래로 드래그해 옮깁니다.
   Tab/Shift+Tab으로 현재 줄이나 선택한 여러 줄을
   들여쓰기/내어쓰기하고 Enter는 현재 들여쓰기를 이어갑니다.
4. **디자인**에서는 홈 화면을 제외한 FigCraft 편집기를 사용합니다. 각 영상에는
   별도의 `design.figcraft`가 생깁니다. 오른쪽 내보내기 영역의 기본 내보내기 버튼 바로 아래에 있는 **라이브러리로 내보내기**로
   선택 요소를 각각 PNG로 저장하거나 페이지를 내보냅니다. 영상 이름 대신 요소·페이지 이름과
   내보내기 접미사를 사용하며 같은 이름이 있으면 번호를 붙여 보존합니다.
5. **편집**은 FilmCraft 0.14.0의 편집기를 내장합니다. 다중 비디오·오디오 트랙,
   클립 이동·분할·트림, 효과·키프레임, 오디오 믹서·볼륨, 자막, 소스·프로그램
   모니터, 작업 영역과 내보내기 화면을 사용할 수 있습니다. 라이브러리 소스를 사이드바의
   **편집**으로 드롭하면 실제 FilmCraft 타임라인에 클립을 배치합니다. 편집기에서 직접
   가져온 외부 파일은 FilmCraft의 원래 방식대로 참조되므로 원본을 유지하세요.

새 타임라인의 기본값은 1280×720, 30fps이며 FilmCraft의 시퀀스 설정에서 바꿀 수
있습니다. 내보내기 모드에서 포맷·해상도·프레임레이트·오디오·자막 옵션과 저장 위치를
선택합니다. 영상마다 별도 편집 프로젝트와 복구 저널을 유지하고, 변경 후 잠시
멈추거나 탭을 떠날 때 저장합니다. 기존 버전의 클립 순서·트림·오디오 위치·볼륨·자막은
처음 열 때 FilmCraft 형식으로 옮기며 이전 데이터도 유지합니다.

라이브러리 썸네일과 미디어 정보에는 FFmpeg/ffprobe가 필요하며 Windows 설치 파일에
포함됩니다. 편집·재생·내보내기는 FilmCraft의 네이티브 엔진과 코덱을 사용합니다.
장치와 드라이버가 지원하면 FilmCraft의 하드웨어 경로를 사용합니다.

## Codex 보조

왼쪽 아래 **Codex**를 클릭하면 현재 탭의 오른쪽에 패널이 열립니다. 같은 버튼이나
패널의 `×`로 닫습니다. 라이브러리와 디자인 탭에서도 사용할 수 있습니다.
Codex 사이드 보기는 탭·창 버튼 바 아래에서 시작해 제목줄 높이까지 사용합니다.
왼쪽 아래 메뉴는 Codex · Codex 가이드 · Video Downloader · 수정 기록 · 휴지통 순서입니다.
설정은 왼쪽 위 로고 옆 톱니바퀴로 엽니다.
입력창은 아래쪽에 고정한 채 위로 늘어나며, 길어지면 내부에서 스크롤합니다.
입력창 아래에서 계정의 CLI가 제공한 모델·추론 수준을 선택하고 빠른 생성을 켭니다.
빠른 생성은 해당 모델이 지원한다고 보고할 때만 사용할 수 있습니다. 선택은 다음 요청부터 적용됩니다.
모델 목록을 불러올 수 없는 CLI에서는 모델 ID를 직접 입력하거나 자동 선택을 사용합니다.
Windows 배포본에는 공식 Codex CLI 0.165.0과 같은 릴리스의 `codex-code-mode-host.exe`,
명령 실행기·샌드박스 보조 파일 및 라이선스가 포함됩니다. 설치 폴더의 `codex/` 파일들은
함께 유지해야 합니다. 수동 지정한 CLI의 보조 실행 파일이 누락되면 온전한 내장 CLI를 사용합니다.
연결되지 않았을 때 패널 중앙의 **ChatGPT로 연결**을 누르고 로그인합니다.
브라우저 연결이 어려우면 **다른 연결 방법 → 기기 코드로 로그인**을 사용합니다.
연결된 상태에서는 대화만 표시합니다. 연결 확인·로그아웃·실행 파일 선택은 상단 `⋯`
메뉴에 있습니다. 인증은 공식 CLI가 처리하며 앱은 인증 정보를 읽거나 별도로 저장하지 않습니다.

보낸 메시지와 답변은 영상별 `codex-chat.json`에 저장되어 다시 열어도 유지됩니다.
요청 즉시 보낸 메시지가 나타나며, 작업 중에는 CLI가 실제 보고하는 단계와 경과 시간을
표시합니다. **작업 내역**을 펼쳐 공개된 도구 실행 정보와 제공된 토큰 사용량을 봅니다.
**중지**로 작업을 취소할 수 있고 앱 종료 시에도 CLI 작업을 중지합니다.
답변의 Markdown은 네이티브 텍스트로 표시합니다. Enter로 보내고 Shift+Enter로 줄바꿈합니다.

현재 영상의 대본·에셋·타임라인을 전달합니다. Codex는 디자인·FilmCraft 편집·라이브러리를
앱 명령으로 직접 수정하고 결과를 확인할 수 있습니다. **대본은 제안 전용**이며, 답변을 검토한 뒤 사용자가 추가합니다. ChatGPT 로그인만 허용하며 API 키 환경 변수는 채팅 프로세스에 전달하지
않습니다. Codex 사용 가능 여부와 한도는 연결한 계정의 구독 상태를 따릅니다.
소스 실행에서는 PATH의 `codex` 또는 직접 선택한 CLI를 사용합니다.

## 수정 기록과 휴지통

왼쪽 아래 **수정 기록**은 오른쪽 패널이 아닌 독립된 작업 페이지를 엽니다.
전체 영상의 이름·채널·마지막 수정 시간·기록 수를 표로 보고 검색할 수 있습니다.
영상 이름은 대본을 열고, **기록 보기**는 그 영상의 저장 기록과 복원 버튼을 엽니다.
상단 탭의 뒤로·앞으로 이동도 지원합니다.

입력이 잠시 멈추거나 영상을 전환·종료할 때 기록하며, 전체 프로젝트의 최근 100개를
보관합니다. 대본·에셋 목록과 해당 시점의 FilmCraft 프로젝트를 함께 복원합니다.
편집 스냅샷은 영상별 `edit-revisions` 폴더에 저장합니다. FigCraft 디자인 파일의
내부 편집 이력은 이 기록에 포함되지 않습니다. 에셋 파일은 복원 중 삭제하지 않습니다.

채널과 영상의 오른쪽 클릭 메뉴 또는 커서를 올리면 나타나는 `⋯`에서 이름을 바꾸거나
**휴지통으로 이동**할 수 있습니다. 채널을 이동하면 그 안의 영상도 함께 보관합니다.
채널과 개별 영상은 각각 복원할 수 있으며 파일은 유지합니다.
영상의 오른쪽 클릭 메뉴에서 **휴지통으로 이동**하면 목록에서 숨겨집니다.
왼쪽 아래 **휴지통 → 복원**으로 원래 채널에 되돌릴 수 있습니다. 에셋과 디자인 파일은
삭제하지 않습니다.

## 설정과 백업

왼쪽 아래 **설정 → 저장 및 백업 → 자동 백업 폴더 → 폴더 선택**에서 위치를 지정합니다.
`Purpose-backup-…` 하위 폴더에 약 10초 간격으로 변경된 파일만 복사하고 마지막 성공 시간을 표시합니다.
**지금 백업**으로 바로 요청하고 **백업 폴더 열기**로 결과를 확인합니다. 자동 백업을 꺼도 기존 사본은 유지합니다.
대본·휴지통·최근 기록을 포함한 `workspace.json`, 디자인, 편집 프로젝트, 라이브러리 파일을 보관합니다.
백업을 켜면 현재 디자인도 주기적으로 저장합니다. 종료 시 마지막 변경을 반영하며, 백업 디스크가
분리되어 실패해도 원본 프로젝트 저장과 앱 종료는 가능합니다.

복원하려면 앱을 닫고 백업 폴더의 내용을 프로젝트 저장 위치에 복사합니다.
라이브러리로 가져오지 않고 FilmCraft에서 직접 연결한 외부 파일은 백업에 포함되지 않습니다.
로그인 인증 정보는 프로젝트에 저장하지 않으므로 백업하지 않습니다.

## 현재 범위

FilmCraft의 공개 버전 0.14.0을 고정한 통합입니다. 편집기의 기능과 미디어 형식 지원은
그 버전의 범위를 따릅니다. 운영체제별 오디오 장치와 하드웨어 코덱은 실제 장치에
따라 달라집니다. Codex는 등록된 디자인·편집 명령을 실행하고 라이브러리에 자료를 추가·배치합니다.
영상 파일의 임의 바이트 변경이나 외부 서비스 게시 기능은 앱 도구에 포함하지 않습니다. 소스와 라이선스는 `third-party/filmcraft-ui/UPSTREAM.md`에 있습니다.
보내주신 P 로고 원본은 사이드바·창 아이콘·Windows 실행 파일 및 설치 파일에 적용합니다.

Windows x64 설치 파일은 `packaging/purpose-video-maker/package.ps1`로
빌드합니다. 설치는 사용자 계정 아래에만 적용되며, 프로젝트 데이터는 설치 폴더 밖에
저장됩니다. CI의 `Purpose video maker Windows package` 작업은 설치 후 실행 및
포함된 FFmpeg의 H.264 인코딩, 실제 전체화면 전환·복원과 작업표시줄용 아이콘 핸들까지 확인합니다. 설치 파일은 코드 서명되지 않았습니다.

다음 배포부터 포터블 ZIP은 만들지 않습니다. 빌드와 설치 검사가 성공하면 GitHub
Releases에 `setup.exe` 하나를 게시하며, SHA-256은 릴리스 설명에 기록합니다.
GitHub가 자동 표시하는 Source code ZIP은 프로그램 설치 파일이 아닙니다.

대본 이미지를 더블클릭하면 모서리 손잡이로 비율을 유지하며 크기를 바꿉니다.
이미지 바깥 클릭 또는 Esc로 조절을 마칩니다. 이미지 폭은 대본에 저장되고 실행 취소에도 포함됩니다.
대본에서 선택한 글자는 파란 배경 위에 검정색으로 표시합니다.
디자인 캔버스의 Ctrl+휠은 캔버스만 확대하고, 캔버스 바깥에서는 UI 배율을 바꿉니다.
저장 알림은 상단 중앙에 약 1초 표시한 뒤 자동으로 닫힙니다.

## UI 아이콘

Purpose의 사이드바·창 버튼·서식 메뉴·Codex와 디자인·편집 도구는 Lucide 1.64.0의
동일한 SVG 세트를 사용합니다. 아이콘은 앱에 포함되므로 실행 중 다운로드하지 않습니다.
화면 배율에 맞춰 그리며 호버·선택·비활성 색상을 적용합니다. 출처와 ISC/Feather MIT 고지는
`assets/ui/lucide/` 및 설치 폴더의 `licenses/lucide/`에 있습니다.


## Codex 가이드와 직접 편집

왼쪽 아래 **Codex 가이드**에서 일반 문서처럼 지침을 작성합니다. **공통 가이드**와
채널별 가이드를 나눠 채널 설명·시청자·말투·목표·편집 원칙을 저장합니다.
매 요청마다 두 가이드를 전달하며, 앱 도구는 최신 가이드를 먼저 읽어야 사용할 수 있습니다.
작업 도중 지침을 바꾸면 Codex가 다시 읽도록 요구합니다.

디자인은 레이어·속성·텍스트 등을 편집하고 PNG 미리보기를 확인한 뒤 라이브러리로
내보낼 수 있습니다. 편집은 실제 FilmCraft 명령으로 클립·타임라인·오디오·자막 등을
수정합니다. 라이브러리는 가져오기·복사·이름 변경·휴지통 이동·복원·디자인/편집에
배치를 지원합니다. 작업 대상은 요청을 보낸 영상에 고정되며, 변경을 보여주기 위해 해당
편집 화면으로 이동합니다. 대본과 가이드는 AI 도구로 수정할 수 없습니다.
편집 명령의 되돌리기는 각 편집기의 실행 취소를 사용합니다.

앱은 공식 CLI에 작업별 전용 MCP 도구를 연결합니다. 계정 연결 방식은 기존 ChatGPT
로그인이며 API 키는 전달하지 않습니다. 일반 파일 시스템은 읽기 전용으로 유지하고
실제 수정은 앱의 편집 명령으로 처리합니다. 도구 연결은 작업 완료·중지와 함께 종료합니다.
Codex에서 쓰던 메시지는 영상별 초안으로 구분합니다. 빠른 생성이 켜지면 번개 내부가 채워집니다.

## 라이브러리와 인터페이스

자료를 클릭해 선택하고 Shift+클릭으로 범위를, Ctrl+클릭으로 개별 항목을 추가 선택합니다.
빈 공간에서 드래그하면 사각형 안의 항목을 선택합니다. 우클릭 메뉴에서 열기·이름 변경·
복사·붙여넣기·휴지통 이동을 사용합니다. Ctrl+C/V, Delete, F2도 지원합니다.
붙여넣기는 다른 영상의 라이브러리에서도 사용할 수 있습니다. 휴지통으로 옮긴 자료도
기존 대본과 타임라인에서 사용 중인 파일은 유지하며, 휴지통 창에서 복원할 수 있습니다.
편집기의 소스와 기존 클립에는 라이브러리 표시 이름이 반영됩니다. 사용자가 별도로
이름 붙인 클립은 보존합니다. 영상의 편집 시퀀스는 대본 소스와 구분해 표시합니다.

**설정 → 모양**에서 설치된 시스템 글꼴을 검색해 앱 인터페이스 전체에 적용하고 영상
아이콘을 선택합니다. 기본 영상 아이콘은 클래퍼보드입니다. 채널과 워크스페이스의
추가 버튼은 행에 커서를 올리면 나타납니다. 대본 제목은 굵게 표시하며 선택 서식 메뉴는
선택한 글자의 오른쪽 아래에 열립니다.

파일 가져오기의 분석·복사는 백그라운드에서 진행하며 진행 상태와 취소를 제공합니다.
다른 영상으로 이동해도 처음 지정한 영상으로 가져옵니다. 마지막 정상 프로젝트 목록을
별도 보관하고, 원본 목록이 손상되면 정상 복구본을 검증해 복원합니다. 손상 원본은
덮어쓰지 않고 별도 파일로 남깁니다.


## 0.1.10 · 수정 기록, 첨부와 공통 UI

- 수정 기록은 영상 행을 누르면 아래에 펼쳐집니다. 여러 영상을 함께 펼칠 수 있고,
  50개씩 이전 기록을 더 볼 수 있습니다. 복원과 대본 미리보기도 목록 안에서 처리합니다.
- 자동 기록은 영상별로 최근 7일은 5분, 8~14일은 1시간, 15~30일은 하루 간격의 최신 상태를
  보관합니다. 복원 전·후 지점은 각 간격에서 별도로 남기고, 30일을 넘긴 기록은 삭제합니다.
  현재 프로젝트와 휴지통·복구용 목록이 참조하는 편집 스냅샷은 보호하며, 참조가 끊긴
  스냅샷만 백그라운드에서 정리합니다. 라이브러리 원본 파일은 이 정리 대상이 아닙니다.
- 설정 → 모양에서 시스템 글꼴과 기본 글자 크기(12~20pt)를 선택합니다. 버튼과 행 간격도
  글자 크기에 맞춰 조정합니다. Ctrl+휠은 이 기준에 대한 별도의 UI 배율입니다.
  선택한 글꼴에 굵은 체가 없으면 제목용 굵은 대체 글꼴을 유지하고, 가변 글꼴은 700 굵기를 사용합니다.
- Codex 입력란의 +, 소스 우클릭 → Codex에 첨부, 라이브러리에서 오른쪽 Codex로 드래그로
  최대 8개 소스를 첨부합니다. 썸네일과 이름을 확인하거나 전송 전에 제거할 수 있습니다.
  이미지(PNG/JPEG/WebP)는 CLI 이미지 입력으로 전달하고 영상·오디오는 경로·종류·길이·자료 ID를
  요청에 함께 제공합니다. 보낸 첨부 목록은 대화에 저장됩니다. 대본의 AI 수정은 계속 제안 방식입니다.
- 편집기의 기본 소스 보기는 영상의 라이브러리 폴더입니다. 시퀀스와 삭제·중복 보관 소스는
  별도 위치에 유지해 소스 개수에 섞이지 않습니다. 상대 경로는 프로젝트 기준으로 해석해 재열기 때
  중복 가져오기를 방지합니다. 기본 클립 이름과 원본 참조를 보존합니다.
- 편집기에서 가져온 파일도 비동기로 라이브러리에 복사하고, 이미 사용한 클립은 해당 관리 파일로
  연결합니다. 편집기의 소스 삭제·실행 취소·다시 실행도 라이브러리 휴지통 상태에 반영합니다.
  자동 폴더 정리와 재연결은 사용자의 편집 실행 취소 단계를 추가하지 않습니다.
- 문서 페이지는 760pt, 목록 페이지는 최대 1120pt 폭을 사용합니다. 제목은 36pt 굵게,
  상단 여백은 48pt, 제목 다음 간격은 24pt이며, 메뉴·선택 메뉴·팝업은 공통 스타일을 사용합니다.
  페이지 경계는 중첩된 프레임 대신 한 개의 얇은 선으로 표시합니다.


## Video Downloader

왼쪽 아래 **Video Downloader**에서 YouTube 등 지원 사이트의 영상 URL을 입력합니다.
**영상 · MP4** 또는 **오디오 · MP3**를 고르고, 저장할 **채널 / 영상 라이브러리**를 선택한 뒤
다운로드합니다. 작업 중 진행률·속도·남은 시간을 보거나 취소할 수 있습니다. 다른 탭을 열어도
작업은 계속되고, 파일 분석·복사를 마치면 선택했던 영상의 라이브러리에 원래 제목으로 추가됩니다.
등록이 실패하면 다운로드한 파일을 보존하여 다시 추가할 수 있습니다. 등록·저장이 확인된 뒤에만
임시 다운로드를 지웁니다. 앱을 종료하면 진행 중인 다운로드와 하위 변환 프로세스를 중지합니다.

Windows 설치 파일에는 Python·yt-dlp·EJS·Deno와 LGPL FFmpeg가 포함됩니다. 자동 업데이트나
브라우저 쿠키 가져오기는 하지 않습니다. 사이트별 접근 제한·로그인·DRM 또는 추출 방식 변경으로
일부 링크는 다운로드되지 않을 수 있습니다. 출처와 라이선스는 `third-party/downloader/UPSTREAM.md`를
참고하세요. Linux 개발 실행에서는 PATH의 yt-dlp와 FFmpeg를 사용합니다.

## 휴지통과 화면 설정

휴지통은 수정 기록과 같은 전체 페이지이며, 검색·복원을 지원합니다. 복원 옆 **영구 삭제**는
확인창을 거쳐 채널/영상/소스 및 앱에 저장된 파일을 삭제합니다. 해당 소스를 사용하는 대본 이미지와
편집 참조는 더 이상 복구할 수 없습니다. 외부 원본과 사용자가 보관한 별도 백업은 지우지 않습니다.
파일 정리 실패는 휴지통 페이지에서 다시 시도할 수 있고, 대기 중 작업은 다음 실행에도 이어집니다.

설정의 **글자 크기**는 텍스트만 조절하며 패널 폭·버튼·아이콘과 화면 배율은 유지합니다.
Ctrl+휠은 기존처럼 UI 배율을 조절합니다. 대본의 선택 텍스트 크기·행간은 문서 서식으로 따로 유지됩니다.
디자인 제목줄 오른쪽의 전체화면 버튼은 작업 영역을 확장하며, 같은 버튼이나 Esc로 돌아옵니다.
