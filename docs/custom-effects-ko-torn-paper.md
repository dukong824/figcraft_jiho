# 커스텀 효과 한국어 이름과 찢어진 종이

사진이나 채워진 도형을 선택하고 **디자인 → 커스텀 → + → 찢어진 종이**를 고릅니다.
원본 이미지·도형과 치수는 유지하고, 화면에 그려지는 윤곽을 안쪽으로 뜯어냅니다.
눈 아이콘으로 비교하거나 효과를 삭제하면 원본 모습으로 돌아갑니다. 슬라이더 조절과
직접 숫자 입력을 지원하며, 한 번의 드래그는 한 번의 실행 취소로 되돌립니다.

| 조절 항목 | 의미 |
|---|---|
| 찢김 깊이 | 기존 윤곽에서 안쪽으로 뜯어내는 정도. 0이면 원본과 같습니다. |
| 찢김 간격 | 큰 굴곡의 간격. 작게 하면 촘촘하고, 크게 하면 넓은 조각으로 보입니다. |
| 가장자리 불규칙도 | 큰 찢김의 들쭉날쭉한 정도. |
| 잔섬유 강도 | 가장자리의 미세한 섬유와 잔결의 강도. |
| 종이 단면 너비 | 뜯어진 곳에 드러나는 종이 단면의 너비. 0이면 색을 덧입히지 않습니다. |
| 종이 단면 색상 | 드러난 종이 속의 색과 불투명도. 사진의 원래 색과 별도로 조절합니다. |
| 무늬 번호 | 같은 값이면 같은 찢김 모양이 재현됩니다. |

깊이·간격·단면 너비는 레이어 좌표의 길이입니다. 레이어를 비례 확대하면 함께 커집니다.
얇은 선이나 작은 글자에는 깊이를 작게 설정하세요. 이 효과는 레이어가 실제로 칠한 알파
윤곽에 적용되므로, 투명 PNG나 배경을 제거한 이미지에도 적용할 수 있습니다.

PNG/JPEG/WebP 내보내기와 캔버스는 같은 CPU 계산을 사용합니다. SVG/PDF는 이 효과가
적용된 레이어를 이미지로 포함해 외형을 보존합니다. `.figcraft`에는 편집 가능한 매개변수를
저장합니다. `.fig`와 Android Vector Drawable에는 대응하는 효과가 없어 생략 경고를 냅니다.
GPU, 모델 다운로드, 서버 통신이 필요하지 않으며 WASM에서도 같은 계산을 사용합니다.
원본 Paper의 새 효과를 가져온 것이 아니라 이 Fork에서 작성한 효과입니다.

## 매개변수 번역 기준

Liquid Metal과 7개 Image Filters의 숫자·체크박스·선택지·색상 이름을 한국어로 표시합니다.
같은 영문 이름도 실제 동작이 다르면 효과별 이름을 구분합니다. 저장 키, 기존 값과 범위,
원본 Paper 셰이더의 계산식은 바뀌지 않습니다. 영문 UI의 이름도 유지합니다.

| 기존 이름 | 한국어 표시 | 구분한 의미 |
|---|---|---|
| Red shift / Blue shift | 빨강 / 파랑 채널 이동 | 천문학의 적색·청색 편이가 아니라 RGB 채널의 어긋남입니다. |
| Frame (ms) | 시작 시점(ms) | 프레임 번호가 아니라 애니메이션 시간 오프셋입니다. |
| Angle, Paper Texture | 빛 방향 | 종이의 회전과 별개인 조명 방향입니다. |
| Angle, Fluted Glass | 골 방향 | 유리의 골이 놓이는 방향입니다. |
| Caustic, Water | 집광 무늬 | 물결의 굴절로 빛이 모이는 코스틱 무늬입니다. |
| Gain C/M/Y/K | 시안/마젠타/노랑/검정 도트 게인 | 원래 망점 크기에 비례하는 잉크 번짐·망점 확대입니다. |
| Flood C/M/Y/K | 각 잉크의 기본 잉크량 | 원본 농도와 별개로 망점 반경에 더하는 기본량입니다. |
| Dispersion, Lens Distortion | 색수차 강도 | 렌즈의 색 분리이며 일반적인 공간 확산과 구분합니다. |
| Focus Center / Edges | 중앙 / 가장자리 선명도 | 해당 영역에서 번짐을 억제하는 정도입니다. |
| Grain Mixer / Overlay | 무늬 입자 강도 / 표면 입자 강도 | 효과 무늬에 섞이는 입자와 마지막에 덧입히는 표면 입자를 구분합니다. |

한국어 이름에는 효과별 문맥 키를 사용하므로, 기본 채우기·선·그림자 등의 기존 번역을
다른 뜻으로 덮어쓰지 않습니다. 모든 매개변수·선택지·색상 이름의 번역 커버리지를 검사합니다.
